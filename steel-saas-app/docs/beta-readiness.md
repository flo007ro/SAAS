# Beta Readiness Checklist

- Users can log in.
- Subscription access is enforced before calculations and report generation.
- Projects store Metric/Imperial units.
- Projects store AISC 360-22 or CSA S16-19.
- Beam, column, and axial compression base plate design runs produce self-contained result_json.
- Factored demand labels are visible in forms and reports.
- PDF reports regenerate from result_json without input_json.
- PDF reports include engineer of record signature block.
- Section database version is stored with every run.
- Section data has been cross-checked against a legitimate source before paid release.
- Validation examples pass for beam, column, base plate, unit conversion, and section lookup.
