# Shared theme and section visualization

The root layout now owns one hexagonal canvas background and the main navigation. The original hex outlines, breathing center dots, cursor illumination, diagonal scan and corner glow remain; the palette is graphite and muted steel/silver. Former page-specific mesh canvases no longer mount. Login, signup, overview, project menus, run forms, results, About and the new `/profiles` screen share this background. Motion respects reduced-motion preferences, pauses when the document is hidden, and renders at a capped device-pixel ratio and frame rate.

The profile viewer builds an extruded W outline from the reference section's depth, flange width, flange thickness and web thickness. It projects and shades actual 3D faces, supports pointer/keyboard rotation, cross-section/isometric views and an optional turntable. No external mesh or extra graphics dependency is used. The form uses its selected reference section; saved results use the historical section snapshot, not today's catalog.

The profile library defaults to the existing AISC W12x40 entry (d=11.9 in, bf=8 in, tw=0.295 in, tf=0.515 in). CSA W310x39 and W310x60 remain explicitly identified as CSA entries. This release does not add other AISC designations or independently certify the catalog source. Root fillets, rolling tolerances, connection details and fabrication geometry are unavailable in the reference schema and are not invented. Extrusion length is illustrative, not a saved design length. Calculations and database schema are unchanged.

Validation: the geometry regression tests check dimensions, envelope area, cap orientation, invalid inputs and length-preserving rotations. Chromium checks covered all application screens, one canvas per page, keyboard/turntable/end-view interaction, profile switching, mobile overflow, retained form inputs, reduced-motion rendering and zero browser page errors. Screenshots and the environment-specific smoke helper are under `/workspace/scratch` (`profiles-desktop.png`, `profiles-mobile.png`, `run-profile-desktop.png`, `run-profile-mobile.png`, and `verify-profile-theme.cjs`).

Browser checks also passed against the local production build, including all six existing regression result pages using their saved section snapshots. No application data was modified by these visual checks.
